# Triage labels

| Role | Label | Meaning |
| --- | --- | --- |
| needs triage | `needs-triage` | A maintainer needs to evaluate this issue |
| needs info | `needs-info` | Waiting on the reporter |
| ready for an agent | `ready-for-agent` | Fully specified; an unattended agent can take it |
| ready for a human | `ready-for-human` | Needs a person |
| won't fix | `wontfix` | Will not be actioned |
| spec | `spec` | A spec issue whose sub-issues are its tickets |
